核心能力What it does

专注内容，也照顾工作流。Focused writing. Practical workflow.

从 Markdown 编辑到文件管理与文档输出，常用工作留在一个轻量桌面空间里。From Markdown editing to file management and document export, everyday work stays in one focused desktop space.

✎

自然写作Markdown writing

多标签编辑、快捷搜索、公式、Mermaid 与脑图，表格保持可靠的源码编辑。Tabbed editing, quick search, math, Mermaid, and mind maps, with dependable source-first tables.

⌘

完整工作空间Workspace files

浏览文件夹树，创建、重命名、移动和回收文件，直接使用系统文件操作。Browse folder trees and create, rename, move, or recycle files using the operating system.

✧

连接本机 GGUF 模型辅助写作；模型文件由用户自行管理，不上传文档。Use a local GGUF model for writing help. Model files stay under your control.

支持 DOCX、HTML 和 PDF 输出，并提供中文公文格式辅助。Export to DOCX, HTML, or PDF, with tools for Chinese official-document formatting.

设计理念Principles

你的文件，
仍在你的设备上。Your files stay
on your device.

Weavien 面向个人写作和知识整理。基础编辑无需联网；本地 AI 是可选能力，模型不包含在安装包中。Weavien is built for personal writing and knowledge work. Basic editing works offline. Local AI is optional, and model weights are not included.

本地优先Local first文档和工作空间使用本地文件。Documents and workspaces use local files.
开放格式Open formats以 Markdown 作为主要写作格式。Markdown remains the primary writing format.
